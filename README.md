# Luxury Perfume Store

A modern perfume storefront built with React, Vite and SCSS.  
The project demonstrates reusable React components, structured styling and the development of a product-oriented user interface.

## Features

- Luxury perfume product catalog
- Reusable React components
- Modular SCSS styling
- Structured product data
- Responsive storefront layout
- Header, banner, product and footer sections

## Technologies

- React
- JavaScript
- Vite
- SCSS
- CSS Modules
- ESLint
